Dataprogram for værestimering

Vi tilbyr et gratis dataprogram utviklet med programmeringsspråket Python som tar i bruk maskinlæring for å estimere gjennomsnittlig nedbør per måned for en gitt lokasjon.

Programmet kan lastes ned fra gjennom denne GitHub linken, men for å ta i bruk programmet kreves det at Python er installert på maskinen.

Programmet kjøres med kommandoen python nedbor.py, og etter oppstart kan man klikke på kartet for å få estimert månedlig nedbørsmengde for det gitte kartkoordinatet, i tillegg til å endre fra månedlig estimat til kvartalvis estimat ved å bruke knappene under grafen til høyre.
